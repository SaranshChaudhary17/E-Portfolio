SETUP
1. Is zip ko extract karo, folder me terminal kholo:
     npm install
     npm run dev        -> http://localhost:3000
2. Content badlo: data/profile.ts (naam, email, about, socials) aur data/projects.ts (apne projects).
3. Git repo me daalna ho to: .git folder ko is nayi folder me copy karo (ya is folder ki files purane repo me paste karo), phir commit + push. Vercel khud redeploy karega.
Note: Home ka 3D head abhi abstract particle bust hai; baad me apna GLB/photo-based model swap kar sakte ho (components/Hero3D.tsx).
